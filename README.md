## 🛠️ 주요 기능 및 요구사항 구현 상세

### 1. 수치 직접 입력 기능 (Input Fields)
- **HTML `<input type="number">` 입력칸 제공**:
  - `관절/축 개수 (N)`: 2 ~ 10개 설정
  - `축 간격 (r)`: 고정축 $O_1 \sim O_N$ 사이의 픽셀 간격
  - `막대 a 길이 (a)`: 굵은 막대(크랭크)의 고정 반경
  - `막대 b 길이 (b)`: 가는 막대(커플러)의 구속 길이
  - `자동 회전 속도 (Speed)`: 초당 회전 각도 (°/초)
- **`설정 적용` 버튼**:
  - 입력한 수치에 맞춰 메커니즘을 즉시 재구성하고 최적의 시점으로 화면을 자동 정렬합니다.

### 2. 마우스 완전 자유 조작 (Free Drag Interaction)
- **Canvas 상의 모든 요소 조작 가능**:
  - **고정축 ($O_1 \sim O_N$)**: 마우스로 클릭하여 원하는 위치로 자유롭게 이동 및 재배치
  - **크랭크 관절 ($P_1 \sim P_N$)**: 마우스로 잡고 회전 및 드래그
  - **자유 관절 ($Q$ 또는 $Q_1 \sim Q_{N-1}$)**: 2차원 공간 어디로든 자유롭게 드래그
- 마우스 오버 시 발광(Halo) 효과 및 커서 상태 변경(`grab` / `grabbing`).
- 마우스 휠로 **줌 인/아웃**, 캔버스 빈 공간 드래그로 **화면 이동(Pan)** 지원.

### 3. 한계 도달 시 연쇄 연동 (Chain Kinematics)
- **PBD (Position-Based Dynamics) & Circle Projection 솔버**:
  - 특정 관절을 드래그하다가 막대 $b$의 길이 구속이나 기하학적 최대 도달 한계(Reach limit)에 도달하면 메커니즘이 잠기거나 튕기지 않습니다.
  - 이웃한 관절과 이전/다음 막대들을 자연스럽게 끌고 가며 연쇄적인 회전과 변위를 유도합니다.

### 4. 자동 회전 및 안전 제어 (Auto-Rotation & Safety)
- **`자동 회전 시작/중지` 버튼**:
  - 첫 번째 구동 막대($O_1 \to P_1$)를 설정된 속도로 매끄럽게 회전시키며 전체 링크 체인의 동역학을 시뮬레이션합니다.
- **안전 자동 일시 정지 (Safety Interlock)**:
  - 사용자가 마우스로 임의의 관절이나 고정축을 클릭하는 순간, **자동 회전이 즉시 일시 정지**되고 안내 알림 배너가 표시됩니다.

### 5. 시각화 및 UI 편의 기능
- **명확한 색상 구분**:
  - 고정축 ($O$): 앤커 지지대와 골드 컬러 (`#f59e0b`)
  - 굵은 막대 ($a$): 두꺼운 스카이블루 메탈릭 캡슐 바 (`#38bdf8`)
  - 가는 막대 ($b$): 슬림 네온 로즈/코랄 바 (`#f43f5e`)
  - 크랭크 관절 ($P$): 에메랄드 그린 서클 (`#10b981`)
  - 자유 관절 ($Q$): 바이올렛 퍼플 다이아몬드/서클 (`#a855f7`)
- **이동 궤적 (Trace)**:
  - `모든 관절 궤적 표시` 체크박스 및 `궤적 초기화` 버튼 제공.
  - 관절별 고유 색상 궤적으로 기구학적 운동 궤적 관찰 가능.
- **상단 대시보드 & 가이드**:
  - 화면 상단에 현재 적용된 $N, r, a, b$ 값 및 회전 상태 실시간 표시.
  - 원클릭 화면 맞춤(Reset View) 버튼 및 조작 팁 제공.
