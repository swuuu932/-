# 2차원 링크 메커니즘 시뮬레이터 (2D Linkage Mechanism Simulator)

직관적인 수치 조작과 마우스 드래그, 그리고 기하학적 한계 도달 시 연쇄 연동(Chain Kinematics)을 지원하는 웹 기반 2차원 직렬 링크 메커니즘 시뮬레이터입니다.

---

## 🛠️ 메커니즘 구조 및 주요 기능

### 1. 직렬 커플러 체인 단일 메커니즘
- **고정축 ($O_1 \sim O_N$)**: 마우스로 클릭하여 원하는 위치로 자유롭게 이동 및 재배치
- **굵은 막대 ($a$)**: 고정축 $O_i$에서 크랭크 관절 $P_i$를 잇는 고정 반경 막대 (길이 $a$)
- **가는 막대 ($b$)**: 인접한 크랭크 관절 $P_1 \to P_2 \to \dots \to P_N$을 직접 연결하는 직렬 커플러 막대 (길이 $b$)
- **크랭크 관절 ($P_1 \sim P_N$)**: 마우스로 잡고 회전 및 드래그

### 2. 수치 직접 입력 기능 (Input Fields)
- `관절/축 개수 (N)`: 2 ~ 10개 설정
- `축 간격 (r)`: 고정축 $O_1 \sim O_N$ 사이의 픽셀 간격
- `막대 a 길이 (a)`: 굵은 막대의 고정 길이
- `막대 b 길이 (b)`: 가는 막대의 구속 길이
- `자동 회전 속도 (Speed)`: 초당 회전 각도 (°/초)
- **`설정 적용` 버튼**: 입력한 수치에 맞춰 메커니즘을 즉시 재구성하고 최적의 시점으로 자동 정렬

### 3. 마우스 완전 자유 조작 & 한계 도달 시 연쇄 연동
- 모든 관절($P_i$)과 고정축($O_i$)을 자유롭게 드래그 가능
- PBD(Position-Based Dynamics) 솔버를 통해 관절이 막대 $b$의 길이 한계에 도달하면 이웃한 관절과 이전/다음 막대들을 자연스럽게 끌고 가며 연쇄 회전 유도
- 휠 줌(Zoom) 및 빈 공간 드래그 이동(Pan) 지원

### 4. 자동 회전 및 안전 제어
- **'자동 회전 시작/중지'** 버튼으로 첫 번째 막대($O_1 \to P_1$) 연속 회전
- 사용자가 마우스로 관절을 잡는 순간 **자동 회전이 즉시 안전 일시 정지**

### 5. 시각화 및 UI 편의
- **색상 구분**: 고정축(골드), 굵은 막대(스카이블루), 가는 막대(네온 로즈), 관절점(에메랄드 그린)
- **이동 궤적 (Trace)**: 모든 관절의 실시간 이동 궤적 토글 및 초기화 지원
- **상단 대시보드**: $N, r, a, b$ 수치와 동작 상태 실시간 표시
